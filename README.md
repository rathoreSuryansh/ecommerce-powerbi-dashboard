E-Commerce Sales Analytics Dashboard(Power BI)

Project Overview

This project is an interactive Power BI dashboard designed to analyze e-commerce sales performance across categories, regions, sub-categories, and products. The dashboard provides both a high-level executive overview and a detailed product-level deep dive to support data-driven decision-making.

Objectives

Analyze overall sales performance
Identify top-performing categories and regions
Understand sub-category and product-level contributions
Enable interactive exploration using filters

Tools & Technologies
Power BI Desktop
DAX (Measures for KPIs)
Power Query (Data cleaning & transformation)

Dataset: Superstore-style e-commerce sales data

Dashboard Structure

Page 1: Executive Overview
KPIs:
Total Revenue
Total Orders
Total Customers
Sales by Category
Sales by Region
Sales by Sub-Category
Top 10 Products by Sales
Order Date slicer for time-based filtering

Page 2: Product Deep Dive
Detailed Sales by Sub-Category
Top 10 Products by Sales (expanded view)
Category & Region slicers for focused analysis

Key Insights

Technology is the highest contributing category by revenue.
West and East regions outperform other regions in total sales.
A small number of products contribute a significant share of overall revenue (Pareto effect).
